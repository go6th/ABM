# Dead code and stale docs purge (fix prompt F, 2026-11-03)

Everything below was **moved**, not deleted (owner rule 2026-10-16): tracked files with `git mv`,
cut-out functions into new files under `unwanted-things/`. The decision record is ADR-0136;
`unwanted-things/README.md` has the inventory rows. `src/` went from 162,235 to 158,158 lines of
Python (`find src -name '*.py' | xargs wc -l | tail -1`; the in-progress workspace-zip import in
the same tree also changes `src/`, so the difference is approximate).

Evidence command for each package or module (an empty result outside the module itself and its
tests is the evidence):

```bash
/usr/bin/grep -rnE "(from|import) <pkg>(\.|\s|$)|\"<pkg>(\.|\")" src/ scripts/ evals/ --include=*.py
```
