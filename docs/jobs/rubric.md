## Heuristic (Working tool or User role)

Source: reference Job Postings workbook (owner's research 2026-10-20), measured 2026-10-29; docs/parity/reference_spec.md (sourced). The platform sentences are a window in the whitespace-collapsed text from the previous '.' or '*' to the next '.' (at most 4 per platform, 3000 characters). The class is `working_tool` when they contain any of these cues (substring, any case): experience, proficien, knowledge, familiar, working with, using, utiliz, document, enter, update, maintain, input, record, log, skills, transactions, data entr, administ, manage; otherwise `user`. Stored as `classified_by = heuristic`; it never decides Build or Admin and owner.
